## Featured work

### FINISH by ABØ Studios
**AI got it built. FINISH gets it ready for users.**  
Production rescue for AI-built and modern web apps: launch blockers, auth, Supabase, Stripe, deployments, responsive issues, and QA.

**Live:** https://finish.abodev.dev

### SweepSign
Responsive SaaS for residential cleaning professionals to create a clear customer handoff after a job, with scope status, notes, photos, and next actions.

**Repo:** https://github.com/Abiola-Obafemi/sweepsign

### NightSignal
A dark interactive signal observatory built with React, TypeScript, Vite, strict tooling, and automated tests.

**Repo:** https://github.com/Abiola-Obafemi/nightsignal
